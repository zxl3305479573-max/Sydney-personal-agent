## 2026-11-04：云电脑截图故障

- 排查真实请求发现原生 Provider 将团队电脑的 home key 与 Bot ID 直接比较，导致启动期间的工作区恢复失败；修正为接受同一空间和用户的团队 home key，保留 Bot 身份、代次及租约校验。超时错误增加方法名用于区分发生步骤。
- 排除标识错误后，真实任务暴露驱动 `execute` 超时：带超时的 Python socket 在探测连接关闭时可能等待数据。改为先做零等待可读性检查，并在命令结束时关闭输出管道；断开连接仍触发拒绝和进程组清理。
- 后台侧定向 5 项通过；完整 Provider 测试 12 项中 10 项通过，2 项已有网络模拟因 ESM 模块不可 spy 失败。云电脑侧 Python 驱动 14 项通过，最初新增测试因误将 socketpair 元组用作上下文管理器失败，修正后重跑通过。
- 后台及云电脑驱动已更新；直接通过隧道验证 PNG，后续从 Web 发起真实截图任务，电脑启动并恢复为 running，任务状态 completed。测试过程中为排查共追加三次截图请求，前两次失败、最后一次完成，可能产生模型调用费用。原生销毁与可信停止仍不支持。

# Bot 状态与持久记忆评测（PA-018、PA-021、PA-022）

评测使用合成账号、Space、项目、Bot 和记忆。每项先执行最低成本的定向回归，再到对应环境核对真实行为。复现失败时修复触发它的链路，复跑对应项后继续。

| 用例 | 操作 | 通过条件 |
| --- | --- | --- |
| S1 发送即退出 | 发送后立即返回首页或项目列表，延迟服务端名单响应 | 成功回执立刻显示正确 Bot 在处理，旧名单返回后标记仍在 |
| S2 恢复会话 | 处理中返回、重进、切换 Space、杀进程重启 | 当前范围已有快照立即显示，断线期间事件能补齐，账号／Space／项目切换后无串数据 |
| S3 Run 生命周期 | 排队、领取、运行、待输入、待接管、完成、失败、取消 | 非终态保留标记，终态收口，过时的回执、快照和事件不会复活已结束的 Run |
| S4 多 Bot 与未读 | 群聊启动多个 Bot，只取消一个，退出后收到回复 | 其余 Run 继续显示，未读绿标保留到明确读到对应消息 |
| M1 双向记忆 | 普通 Bot 与项目 Bot 分别写入、对方读取，同样检查设置页和运行提示 | 同一用户与 Space 共享持久记忆，旧文档及其版本仍可取回 |
| M2 编辑冲突 | 两个入口修改同一版本，重进并删除可删除文档 | 后写收到冲突，成功的修改使用数据库时间，重进稳定排序，删除后无旧缓存复活 |
| M3 隔离 | 以另一个账号、Space 或错误项目读取文档和复用上下文 | 同账号同 Space 的共享记忆可用，跨账号、跨 Space 及未经授权的项目数据访问被拒绝 |
| M4 语义记忆 | 配置具备共享能力的 Provider，测试普通与项目会话互存互查 | 共享持久事实可检索，历史摘要保留在其原来的会话范围内 |

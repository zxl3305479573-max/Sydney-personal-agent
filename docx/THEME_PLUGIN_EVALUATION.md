# iPhone 声明式换肤评测

日期：2026-11-21。关联 PA-018、PA-019、PA-020、PA-021。阶段状态只在 [总计划](PLAN.md) 维护。

## 范围与完成条件

本轮交付 iPhone 本地主题包、全局与页面类型分配、经典／卡片布局、导入／替换／卸载／恢复，以及源码离线候选。允许一个全局包与多个局部包并用；局部范围不扩大到其他页面。Windows、在线市场、实例级绑定、同步、提交推送、生产变更和发布不在本轮范围。不调用子代理。

采用 Stop That Shit 的 Stop Ladder：需求与现有保证先行，复用已有模式、存储和文件选择能力，以具体失败路径决定验证，不新增通用执行宿主。此为技能指导，不声称已有机器强制钩子。界面沿用现有 iOS 组件及 Impeccable 的 Operate 原则。

基线：经典／午夜、模式存储和页面插槽已存在。2026-11-21 的 [OTA 产物复核](VALIDATION.md#iphone-界面模式-ota-产物复核2026-11-21) 确认 1.0.17 已分发该内置功能；旧文档“未发布”是历史时点，不代表当前发行状态。既有 46／64 项通过记录不是本轮改动后的验证结果。

## 离线候选与实机操作

离线候选包含本工作区源码、全局及局部示例 `.sydney-theme.json`、定向检查命令与结果和已知限制。不是签名 IPA 或已发布 OTA。正式发布沿用既有流程，不能因离线 Goal 完成而标记生产可用。

真机在含候选功能的兼容版本中，从「设置 → 界面模式」导入两个示例。依次验证全局应用、只绑定首页、分别绑定单聊／群聊、页面往返、用户背景、预览取消、重启和卸载。记录实际版本、系统、字号与脱敏截图；本轮未执行的操作保持待验，不记录个人数据。

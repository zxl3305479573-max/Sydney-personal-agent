# 首版需求验收清单

更新日期：2026-11-04。此表汇总证据和待验证项，不替代 [总计划](PLAN.md) 的阶段状态，也不代表生产验收。需求原文见 [产品需求](../docs/requirements.md)；运行与测试记录见 [验证记录](VALIDATION.md)。

| 编号 | 现有基础 | 尚需完成或验证 |
| --- | --- | --- |
| PA-001 | 任务 API 和工作台已有创建、查询接线 | 真实数据库与浏览器创建查询闭环 |
| PA-002 | 已定义公开网页摘要工程任务 | 选定模型与服务器，执行真实工具，核对结果和下载 |
| PA-003 | 有任务状态、历史读取与工作台投影 | 真实步骤、时间、错误及结果显示的完整性和浏览器联调 |
| PA-004 | 有 mandate、范围检查和工具门禁 | 真实授权撤销、到期与并发检查；越权请求的用户交互按当前实际支持情况验收 |
| PA-005 | 有运行状态、效果记录和中断处理初版 | 模型与工具失败、重启及未知副作用的真实恢复演练；停止证据尚不可用 |
| PA-006 | 排队取消及运行中尽力中断已接线 | 真实队列竞争、执行中取消与结果核对；不能把中断信号视为停止证明 |
| PA-007 | 显式记忆复用现有存储和授权资源 | 保存、查看、修改、删除及后续检索的完整用户流程 |
| PA-008 | 有任务历史读取与展示初版 | 按编号或关键词查找结果的实际用户流程与权限验证 |
| PA-009 | 有原生部署和运维草案 | 新服务器安装启动、配置错误提示、升级和回滚实测 |
| PA-010 | 有账号分离、授权、路径和审计设计及代码初版 | 服务器权限、敏感数据日志、删除和外发边界实测；见模块审计 |
| PA-011 | 有单次桌面预览接线 | 实机截图、状态和分辨率；流式观看及断线重连尚未完成 |
| PA-012 | 有桌面动作、文件和命令驱动初版 | Linux 输入、截图、文件和终端联调，以及账号授权边界验证 |
| PA-013 | 有统一 Provider 与原生状态查询初版 | 真实接入、状态、重连和断开验收；不支持的生命周期操作须明确显示 |
| PA-014 | 有尽力中断与保守后台状态查询 | 可信进程归属和停止证据、输入阻断与人工接管恢复均未完成 |
| PA-015 | 规划后台与桌面不同账号 | 在目标 Linux 验证密钥、数据库及管理接口不可被桌面账号读取或调用 |
| PA-016 | Provider 暴露部分能力声明 | 在界面核对持久性、失效和文件保留；快照及恢复按实际能力明确不可用 |
| PA-017 | 有 Provider 接口、工厂及测试替身 | 同契约测试和真实 Provider 行为均需在完整环境运行 |
| PA-018 | 有任务工作台与电脑预览初版 | 目标分辨率下的完整交互、结果及不可用能力展示；人工接管仍不可用 |
| PA-019 | 已有未接入生产的插件宿主离线试点 | 用户撤销该需求，不再推进；历史记录保留 |
| PA-020 | Web 已接入背景、气泡、搭配和 IndexedDB；移动端已接入本机背景、气泡预设和 SecureStore；定向测试及两端类型检查通过 | 真实浏览器和手机图片选择、持久化、视觉与键盘、辅助功能、目标尺寸和实际部署未验收；两端暂不跨设备同步 |

测试结果与风险细节以 [模块审计](../docs/audit/README.md) 和验证记录为准。真实 App 的选择与接入排在首个网页摘要闭环之后；其 OAuth、数据外发和撤销边界须另行明确。

# 手机端导航、GitHub 与会话模型测评

日期：2026-11-20。关联需求：PA-021、PA-022、PA-024。阶段状态统一维护于 [PLAN.md](PLAN.md)，实际命令及结果归档于 [VALIDATION.md](VALIDATION.md)。

## 目标与范围

`1.0.17` 使用贴底全宽的「聊天／应用／项目／GitHub」导航栏，四个入口等宽、上图标下文字。首页选中「聊天」，各模块主页面选中对应项。主页面间切换不堆叠历史，模块页点「聊天」返回首页。会话详情、电脑、项目详情、应用连接／添加、仓库详情和设置页隐藏导航。应用页保留既有连接、OAuth 回跳及设置入口。

复用现有 GitHub 原生页面及后台 RPC，完成公开搜索、PAT 绑定、个人主页与贡献年份、仓库列表／筛选／分页、README／提交／发布速览及 Bot 分析草稿。令牌不在手机持久化。保留现有空间／账号隔离和旧草稿。

构建 `2` 安装后，用户确认 GitHub 可以连接，反馈点击页面操作会拉出下拉刷新动画。修复范围为手机 GitHub 页的加载反馈。切换年份、筛选、搜索、翻页和打开详情时在后台加载，手动下拉保留刷新反馈。使用现有 RPC 和原生底座，定向回归后生成独立 IPA 候选。

交付已实现的新会话默认模型名称、选择页当前项、保存后回显及恢复继承行为。源码、离线测试、后台上线、OTA 下载和真机生效分别记录；只有目标手机实际通过验收才算整体完成。Windows 更新机制、项目工作区迁移与实验开关不在本次实施范围。

## 前置条件与发布边界

- 使用仓库现有依赖；本机仅编辑和限定单 worker 离线验证，不启动 Docker、数据库、桌面服务或全工作区构建，不重新安装依赖。
- 保留工作区其他未提交改动，不自行提交或推送，不调用子代理。遵循用户指定的 Stop That Shit 技能，复用现有功能，按已知缺口实施。
- 后台发布前重新核对 GitHub 单表及迁移账本、服务候选和备份；只允许本次 GitHub 所需迁移，不运行全部待迁移，不夹带项目目录／会话发布。
- 更新前识别目标手机的 bundle、runtime、channel 和实际更新信息。兼容 JS 优先使用既有 OTA。通道无法发布时，从匹配的旧未签名底座生成独立侧载备选，重新生成嵌入 bundle、资源和清单，按原侧载身份签名。准备阶段仅产出并验证未签名包；签名安装、生效与 OTA 逐项记录。PAT 仅由用户在手机安全输入，不写日志或文档。

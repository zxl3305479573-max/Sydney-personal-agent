# 手机端五项任务实施方案

关联需求：PA-010、PA-012、PA-017、PA-021、PA-022、PA-023。状态统一维护于 `docx/PLAN.md`。以原生 iPhone 客户端为目标，保留现有后台和数据，不采用网页添加到主屏幕作为替代。

## M1 现有功能与真机验收

- 范围：核对安装包和后台版本；按登录、会话恢复、聊天收发、头像、群聊、置顶、账户和应用连接顺序排查，修复可复现问题。X 应用 OAuth 继续单独记录，不阻塞其他能力。
- 交付：功能与版本对照、缺陷复现及修复、定向回归和 iPhone 验收记录；不记录账号、验证码、消息内容或令牌。
- 依赖与验收：可访问的授权后台、真实安装版本与测试账号；分别覆盖正常、失败、退出重登和账号切换。代码存在或模拟通过不代表线上可用。

## M2 云电脑画面与接管

- 范围：核查屏幕票据、noVNC 画面、人工控制租约、触摸/键盘输入、释放和断线；先复现再修复，兼容当前设备类型和后端能力。
- 交付：针对性修复、单位及协议测试、授权环境和设备复测记录。
- 依赖与验收：匹配版本的 API、屏幕代理和驱动；真实 iPhone 分别验证画面、申请控制、点击、长按、滚动、键盘、横竖屏、异常断线、租约过期和退出释放。不把画面可见等同于接管成功。

## M3 手机项目独立界面

- 范围：屏幕底部玻璃入口、独立项目页面、工作区列表及空/加载/错误状态；后续支持文件夹切换、Bot 和群聊。现有未接线列表组件先审查并回归。
- 交付：符合原生导航与 Web 手机视觉的界面、无障碍及定向测试；真实功能使用经授权的服务端接口。
- 依赖与验收：后端完成用户/Space/文件夹隔离、创建与删除并发门禁、工作区清理和数据库验证前，不开放真实创建、删除或虚构数据；移除默认不删除真实目录。验证切换、误触、长名称、读屏、加载和设备安全区。

## M4 手机与桌面联动

- 范围：复用后台认证、设备身份和现有数据；展示可证明的设备状态、项目来源和任务状态。电脑本地目录仅在桌面可信授权与设备连接机制完成后开放。
- 交付：接口和状态映射、设备离线与撤销反馈、双端账号/空间隔离和必要测试。
- 依赖与验收：可信设备标识、服务端授权和桌面连接器；验证同账号双端、跨账号拒绝、断线重连、切换设备和撤销。手机不能直接持有服务器维护凭据或访问未授权路径；不展示未经实际检查的“在线”状态。

## M5 原生视觉与在线更新

- 范围：延续现有玻璃组件和 Web 字体参照，检查浅深色、安全区、触摸尺寸、动态字体及旧系统回退；沿用现有可选 Expo 更新配置。
- 交付：按页面分批调整、无障碍与视觉记录、更新检查和错误反馈测试，以及构建、发布与回滚说明。
- 依赖与验收：iPhone 视觉与性能实测；在线更新需用户控制的 Expo 项目、正确运行时与构建、首次重装、发布和回滚验证。原生依赖变化需要新的安装包，侧载签名与更新不是同一件事；未配置时准确提示不可用。

## 顺序与协作

M1/M2 的问题核查、M3 的未接线界面准备、M4 的设备接口盘点和 M5 的更新/视觉核查可并行；M3 实际数据接线依赖 PA-022 服务端门禁，M4 本机文件能力依赖桌面安全授权。每项由独立审核复核并修复有效问题，再由总窗口汇总；修改共享文件先登记实际写集。当前环境若不能创建独立对话，应如实记录，使用可用子代理分工而不虚称新窗口。每个可验收模块同步开发、验证、计划及受影响运维文档。

真实设备、服务器和构建结果分别留证；不在本机自动启动数据库、桌面服务或执行全仓构建。涉及线上变更前核对版本、备份及回滚，继续保留网页入口直至双端迁移验收。

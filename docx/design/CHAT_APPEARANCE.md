# 聊天外观设置方案

日期：2026-11-04。关联 PA-018、PA-020；Web 首版代码已接线，阶段状态以 [总计划](../PLAN.md) 为准。用户已决定不建设自定义插件系统，聊天换肤不依赖执行外部代码的插件宿主。

2026-11-05 PC 扩展：新增“简洁默认”和“自定义”模式；简洁模式保留原有素材和选中搭配，切回自定义后恢复。旧配置未记录模式时继续沿用原有选择。用户与助手气泡可分别选择本地 PNG、JPEG 或 WebP 图片，每张最多 5 MiB，按覆盖方式显示；图片和配置仍保存在浏览器 IndexedDB。气泡图片可能降低文字对比度，需用户检查预览。此扩展尚未完成真实浏览器、桌面客户端和移动端验收。

PC 气泡颜色选择器提供原生选色、HEX、预设色和受支持浏览器的屏幕取色；纯色不透明气泡显示文字对比度。新建气泡黑底白字，已有配置保留；透明度继续通过气泡设置调整。RGB/HSL/OKLCH 输入、自存色板及实际浏览器验证暂未完成。

## 当前基础与目标

Web 已有浅色、深色、跟随系统和浏览器本地外观偏好，样式使用共享变量；聊天消息已有用户气泡颜色及部分按上下文指定的颜色。现有能力不等同于背景图、可编辑气泡或搭配管理已实现。

本次实现：Web 设置中可添加 PNG/JPEG/WebP 背景（每张最多 5 MiB），调整填充、透明度和遮罩；可独立添加、选择、删除及命名气泡样式，分别设置双方颜色、透明度、圆角和边框；搭配支持保存、选择、重命名和删除。预览即时应用，保存或取消后确认；图片与配置存入当前浏览器 IndexedDB。移动端设置中可选择本机图片、删除背景和选择内置气泡预设，图片复制到应用文档目录，配置写入 SecureStore；移动端当前不提供 Web 的多项编辑器和搭配管理。当前 Web 聊天显示规则为用户已发送文字无背景气泡，助手正文采用头像、名称和无气泡正文布局；自定义样式中的前景色仍可影响文字，背景图、圆角和边框不应用于这两类正文。两端都不上传图片或配置，也不跨设备同步；真实浏览器和手机验收尚未完成。

在设置增加“聊天外观”：背景图和气泡样式独立添加、选择、编辑与删除；可将当前背景与气泡组合命名保存，以后整体切换。改动先预览，用户可保存或取消；恢复默认后原有聊天功能仍可用。添加或切换皮肤在运行中生效，不重启后台、不重建或刷新前端。

## 首版范围

- 背景：从本地选择图片，预览并调整填充方式、透明度与遮罩；支持添加多张、切换及删除，删除当前背景时安全恢复默认。
- 气泡：分别调整用户和助手消息的背景色、文字色、透明度、圆角及边框；支持保存多套样式、切换与删除。助手当前的消息呈现方式需要实施前核对，修改不得破坏 Markdown、附件或操作按钮。
- 搭配：保存背景与气泡的组合，重命名、切换和删除；若引用的背景或气泡被删除，保留可理解的回退状态，不出现不可恢复的空白界面。
- 预览与无障碍：取消编辑恢复原选择；提供清晰文字、焦点状态及必要的遮罩或对比度提示。浅色、深色、跟随系统保持可用；具体覆盖顺序实施时应兼容现有 Bot 气泡颜色，不静默覆盖已有用户设置。
- 数据与隐私：首版建议仅保存在当前浏览器，图片使用适合二进制数据的浏览器存储；不上传到后台或发送给模型，不依赖新数据库或服务。显示存储失败、配额不足、无效图片和缺失资源的提示，并允许恢复默认。跨设备同步、导入导出及共享主题包待另行决定。

## 分阶段交付

1. 核对聊天消息结构、现有颜色优先级、设置入口及浏览器存储限制，确定兼容和回退规则。
2. 实现 Web 与移动端的本地背景和气泡配置、预览、保存和恢复；不改变后台或任务执行链。
3. 实现多个背景、气泡及搭配的管理，覆盖删除引用、刷新恢复和存储失败。
4. 完成定向测试、PC 浏览器交互和主要窗口尺寸验证；据实际验证结果记录限制，再决定是否增加跨设备同步。

## 验收条件

- 用户能添加两张图片和两套气泡样式，分别切换并保存两套搭配；操作即时生效，不重启或重新构建应用。
- 保存后刷新浏览器仍能恢复所选外观；取消预览、删除当前资源、数据缺失或本地存储失败时可恢复默认。
- 移动端可从设置进入外观页面，选择和删除背景、切换内置气泡预设，重新打开应用后可读取本机配置。
- 浅色、深色、跟随系统、现有 Bot 颜色、消息 Markdown、附件、选择复制及操作按钮不出现阻断性回归。
- 背景和气泡不遮挡文字或主要操作，键盘可完成关键设置；图片不进入模型上下文或后台。
- 定向测试、浏览器及目标尺寸实际结果分别记录；尚未运行的验证不得记为通过。

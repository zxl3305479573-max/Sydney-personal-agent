# 首个工程任务与验收约定

日期：2026-11-03。关联需求：PA-001 至 PA-006、PA-009、PA-010、PA-017、PA-018。

状态：工程验收场景已定义；真实高频业务场景、生产模型与服务器仍待用户确定。本文件不能作为用户已批准对外发送数据或操作真实账号的依据。

## 1. 场景

用户提供一个无需登录的 HTTPS 网页，要求读取页面并在任务工作区生成带来源的 Markdown 摘要，通过已有文件下载入口获取产物。先使用离线网页、模型和工具替身验证结构化执行结果；P5 再在授权服务器验证真实网页和桌面操作。

| 项目 | 工程约定 |
| --- | --- |
| 输入 | 用户指定的一个公开 HTTPS 页面、摘要要求、工作区中的目标文件 |
| 输出 | 指定位置的 Markdown 文件、来源 URL、任务及执行记录 |
| 完成证据 | 工具确认文件存在且可读；下载内容与工作区文件一致；来源引用对应输入 |
| 内容质量 | 人工核对摘要与来源；不以关键词匹配或模型自行宣称完成代替质量验收 |
| 账号 | 离线测试无需账号；真实公开页面无需登录；模型连接另行授权 |
| 允许操作 | 读取明确指定页面、在指定文件写入可恢复产物、下载该产物 |
| 不在场景范围 | 登录个人账号、提交表单、发消息、安装软件、读取后台文件、任意终端命令 |
| 失败处理 | 保留记录，说明产物是否存在；不自动将半成品标为完成 |

URL、资源标识和文件路径由可信工具适配层解析，不能由模型声称“已规范化”。重定向目标、解析后的内网地址及符号链接目标必须重新检查。第一阶段纯内核只比较已规范化的资源标识，不承担文件系统或网络检查。

## 2. 离线验收

1、同一任务重复派工请求不会产生两个新执行意图；重试保留先前执行标识。
2、有效的任务授权仅覆盖同一用户、空间、Bot、任务和 Run，以及同一工具、动作和资源组合。
3、同一个授权条目不能拼接另一条目的资源权限；过期、撤销、外部内容伪造的授权被拒绝。
4、暂停审批或人工接管期间不能调度新动作；取消后不能因重试而恢复执行。
5、结果未知的副作用必须先核对；进程中断不能当作操作未发生。
6、最终产物与下载验证属于 P3/P5；纯策略测试通过不能代替此闭环。

## 3. 数据发送与预算设计

模型可接收的候选内容为：用户任务、必要的页面正文片段、工具结构声明、脱敏工具结果和完成任务所需的最近上下文。默认不发送后台密钥、整个用户目录、无关历史或完整浏览器配置。截图属于可能包含个人信息的数据，真实桌面测试前单独确认发送范围。

预算分为模型调用次数、工具动作次数、单次超时、任务总时限和供应商实际用量。各项由配置提供；离线测试使用固定时钟和显式数值，不将测试值发布为生产默认值。任务级总 token 硬上限尚未实现，不能把现有单次输出限制称为任务总成本控制。

供应商没有返回某次调用用量时，该次和累计完整性标记未知；不能按零计算，或据字符数捏造实际费用。重试、子 Agent 和失败调用都属于任务用量。价格、预算数值、生产模型及保留期仍待确定，本轮不调用真实模型。

## 4. 本轮实施边界

P1 的接口映射与原生桌面设计并行完成后，P2 先实现应用代码仓库中可离线验证的纯派工策略和授权检查，不增设数据库、队列或运行时。授权签发、持久化事务、执行入口接线和 UI 尚未实现。策略的允许结果不代表工具已经执行，也不替代数据库租约、审批或操作系统权限。

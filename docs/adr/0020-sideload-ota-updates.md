# ADR-0020：侧载 iPhone 的在线更新

日期：2026-11-10

状态：代码已实现，项目配置和实机发布待验证

## 背景与决定

PA-021 需要在普通 Apple 账号侧载的原生 App 中接收 JavaScript 和资源更新。复用已有 Expo Updates：Sydney 侧载构建仅在显式配置独立 Expo 项目标识、所有者及运行时版本时启用，固定使用 `sideload` 通道；缺少全部配置时保持关闭，部分配置或沿用上游项目时构建失败。

免费 Expo 项目提供有限额度，额度以 Expo 实际政策为准。此决定不购买订阅、不新装原生依赖，也不将上游项目作为更新源。更新源拥有者及其发布凭据可以向客户端分发可执行 JavaScript，必须由用户控制；当前实现未配置端到端更新签名。不得在仓库或日志中保存令牌。

## 兼容性与限制

运行时版本由发布者明确维护。原生依赖、Expo SDK、原生配置或原生能力改变时必须更换运行时版本并重新构建、签名和安装 IPA，不能向旧运行时发布包含新原生接口的更新。手工确认版本不等于自动兼容性验证。

OTA 不能更换原生二进制或延长 Apple 侧载签名期限，既有关闭更新的安装包需要先重装启用更新的版本。更新与回滚、失败恢复、免费额度以及设备签名续期必须在实际账户、服务和设备上单独验证。

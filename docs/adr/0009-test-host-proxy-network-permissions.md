# ADR-0009：测试服务器代理的网络权限

- 状态：测试环境已实施，尚未用于项目生产部署
- 日期：2026-11-04

## 背景

用户要求测试服务器的应用流量使用代理规则，同时保留远程管理和私网通信。原有本机代理端口需要应用主动设置，无法覆盖未配置代理的程序。

## 决定

在测试服务器上为专门的 Mihomo systemd 服务启用 TUN 自动路由，并授予 `CAP_NET_ADMIN` 和 `CAP_NET_RAW`。这两项能力允许该服务改变宿主机网络，属于高权限；代理程序及其配置必须受信任、限制写入，不能授予桌面账号或 Agent 工具。该措施不改变云电脑 Provider 的权限边界，也不作为多租户隔离方案。

当前规则让私网直连、其他匹配流量走订阅节点；SSH 服务端回程使用主路由表。系统 DNS 未整体接管，已为部分 HTTP/TLS 流量启用域名嗅探，不能视为完整 DNS 防泄漏方案。容器转发、其他协议、重启后的路由和实际故障回滚均未验收。

## 后果

本机普通用户和 root 发起的部分 HTTPS 请求已实测经路由访问，现有 SSH 与桌面隧道仍可用。程序拥有宿主机网络管理能力会扩大受攻击面，后续必须验证更新、故障恢复、容器和 DNS 策略；生产部署前应重新评估权限和隔离，不得以本次测试代替安全验收。配置和回滚记录见 [运维手册](../../docx/OPERATIONS.md)。

# ADR-0018：Linux 云电脑只读远程检查

- 状态：提议；独立检查工具已编写，实机待验
- 日期：2026-11-08
- 关联需求：PA-009、PA-010、PA-013、PA-015、PA-017

## 背景

自动准备之前需要了解已有 Linux 电脑的环境。目标可能由用户自行管理；仅知道地址不构成对主机身份的确认，也不应将控制服务器凭据或任意命令交给目标。

## 决策

首步提供独立的只读检查工具，调用系统 OpenSSH 并指定单独的身份文件及用户预先核验的 `known_hosts`。关闭交互、身份代理、转发和外部 SSH 配置，强制校验主机密钥；通过标准输入发送仓库内固定检查脚本，不接受自定义远程命令。超时或失败不自动重试。

此工具暂不接入 API、网页、模型工具或多用户服务。它使用执行者可读取的本地凭据，不能作为用户级凭据管理与服务器出站授权的实现。加入服务端前必须设计账户隔离、目标网络策略、凭据加密、审核和审计。

单机命令行可在所有者私有文件中保存多份连接档案，只保存身份文件与 `known_hosts` 的绝对路径，不复制私钥。使用 Linux 文件锁与原子替换串行化档案更新；该机制不是账户级隔离，也不切换应用实际电脑。新主机密钥文件只能在核对用户提供的 SHA-256 指纹后创建，拒绝覆盖现有文件。

## 影响与验证

需要用户事先通过可信渠道核对并配置主机密钥，并提供已授权的无交互 SSH 身份；不读取密码或自动信任首次连接。SSH 检查本身不修改目标配置，但远端执行 Python 有进程与资源开销。检查输出由目标主机控制，只可作为待核实的信息，不能证明服务安全或自动授权安装。

Windows 离线测试、Linux OpenSSH 和真实远端的可用性分别记录；变更主机身份、密钥或凭据管理方案时重新审查。本决定不实现安装、目标切换或任务隔离。

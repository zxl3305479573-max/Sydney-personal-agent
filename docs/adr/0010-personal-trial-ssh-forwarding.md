# ADR-0010：单人使用的双机 SSH 转发权限

- 状态：两机已配置，截图与基础协议已验证；真实任务及恢复未验收
- 日期：2026-11-04
- 关联需求：PA-009、PA-010、PA-012、PA-015

## 背景与决定

两机试接发现，云电脑禁止 TCP 转发时，现有 OpenSSH 配置也拒绝后台到驱动的 Unix socket 转发。用户明确项目后期为其本人长期使用，并同意使用放宽转发权限的连接方式。

云电脑对专用 `sydney-tunnel` 账号启用 `AllowTcpForwarding local`，后台通过 SSH 本地 Unix socket 转发连接驱动。保留专用密钥、已核验的主机密钥、chroot、禁止交互终端及独立桌面账号。驱动继续以桌面账号运行，不获得 root 或后台服务权限。

## 后果

持有后台隧道密钥者可能通过该账号访问云电脑可达的其他 TCP 服务；chroot 不阻止 TCP 访问。后台密钥和控制账号应限制读取，不能将此方案描述为仅可访问驱动 socket 或多租户隔离。

跨机 provision、状态、无租约文件操作拒绝和真实桌面截图已通过；服务重启、桌面重登、断网恢复、模型任务与可信停止均未验收。驱动当前绑定桌面 `:10`，桌面会话变化后可能失效。停止使用时按运维手册停止隧道并恢复转发限制；更窄的受限代理仍可后续评估。

# ADR-0014：受控的热插拔扩展

状态：已撤销（2026-11-04）。用户决定不建设自定义插件系统，聊天换肤改按 [聊天外观方案](../../docx/design/CHAT_APPEARANCE.md) 规划。以下保留历史决策，不作为当前实施要求；固定宿主和生命周期试点未接入生产。

## 背景

用户要求插件运行中启停和升级不重启核心。现有 Rakazo 插件安装支持技能及 MCP 配置，不等于具备第三方代码隔离或通用热插拔进程宿主。当前取消、授权和云电脑隔离仍需验收。

## 决定

将独立进程宿主、核心持有的调用网关和明确版本的协议作为目标方向；插件默认禁止运行，运行位置与权限由管理者配置并经目标环境验证。独立进程本身不是安全沙箱。复用现有审批、租约、外部效果和安装能力，不构造平行执行链。进程宿主不依赖 Docker，但具体 Linux 隔离方案尚待评估与验证。

启用以前核验版本、配置、授权和健康；停用先阻断新调用，在途效果和退出证据分开记录；升级计划采用新旧代并存和受控切换。授权扩大须重新审批。无法确定外部效果时保持未知，禁止自动重放。

## 后果

插件故障应限制在插件能力范围内，不能承诺已发出请求无副作用或正在使用该插件的任务不失败。现阶段仅实现不执行代码、不注册能力、不改变现有产品行为的纯生命周期决策；宿主、隔离与热插拔仍未实现。详细边界、风险和验收见 [设计](../../docx/design/HOT_PLUGIN_SYSTEM.md)。

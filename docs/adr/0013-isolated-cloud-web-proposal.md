# ADR-0013：云电脑隔离运行 Web 的验证方案

- 状态：已切换试运行，完整恢复和屏幕验收待完成
- 日期：2026-11-04
- 关联需求：PA-009、PA-010、PA-012、PA-015、PA-017、PA-018

后台主要内存占用来自 API、Worker 和 Web。Web 预览服务承担内容安全策略、API 代理和远程桌面代理，不能直接替换成静态文件服务。候选方案是在云电脑隔离网络命名空间中运行与现网一致的 Web，通过专用账号和 SSH Unix 套接字连接后台 API 和屏幕；后台仅回环监听 Web 转发入口。

后台数据库和通用认证密钥不迁移。云电脑隔离服务仅获得现有独立屏幕代理密钥；该密钥仍具备屏幕授权查询能力，必须限制为服务账号可读。专用隧道密钥仅允许连接后台指定回环端口及指定回环监听，不允许执行命令。云电脑桌面账号不得读取密钥、访问套接字或进入隔离网络。

已切换至云电脑 Web：后台以回环 socket 和 `systemd-socket-proxyd` 转发，旧 Web 服务保留但禁用。切换前后验证首页、真实认证、Bot 列表、屏幕传输及无效授权拒绝；隧道重启后恢复。当前没有运行中的电脑，无法完成有效屏幕授权的真实页面验收，该项仍须在电脑运行后复测。运行环境和依赖同步、云电脑及后台重启恢复、回滚演练、SSH 授权撤销和备份仍待验证；这次验收不代表长期生产可用。

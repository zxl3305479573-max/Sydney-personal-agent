# ADR-0017：Hersona 人格模板及用户人格卡片

状态：本地实现，待数据库及浏览器验收（PA-018）。

Hersona 的 `attributes/` 模板按 CC0 1.0 发布，来源为 `shiro-0x/hersona`，固定提交 `75146c9126e1614750eeead3da165d61a3fc2188`。项目保留其中性格、语气、角色及兴趣四类 300 个属性的精简快照；外观类未接入。上游代码以 MIT 发布，本实现不调用其 Python CLI 或 MCP 服务。属性名称和部分正文来自上游，仍可能是英文或日文。

Sydney 在本地读取属性描述，检查双向冲突，并用轻度、适度和明显的措辞生成指令。该实现不是上游 Hersona 混合算法的完整移植，也没有声称支持其基准测试、推荐或角色锁定等其他功能。用户可额外编写自定义指令；自定义卡片存入数据库，以账号 ID 限定读写并配置 PostgreSQL 行级策略。

应用人格时把生成的指令复制到 Bot 原有 `instructions` 字段；后续编辑或删除卡片不修改已有 Bot。模板存储本次尚未纳入账户导出，完整数据库备份仍是恢复方式。数据库迁移、真实行级隔离、浏览器及跨设备行为均待实际验证；尚未部署。

# ADR-0019：Linux 云电脑依赖准备原型

- 状态：提议；原型待验证，未接入应用
- 日期：2026-11-08
- 关联需求：PA-009、PA-010、PA-012、PA-013、PA-015、PA-017

## 背景

已有 Linux 云电脑可能缺少桌面、截图和画面组件。安装涉及用户系统包、软件源、sudo 权限及网络，不能因为 SSH 可以登录就自动执行。实际发行版、仓库和现有服务各异，不能把示例 systemd 单元当作通用安装器。

## 决策

实验性命令行工具将 Ubuntu 22.04 和 24.04 的 x86-64、ARM64 列为候选，而非已验收的支持范围。先只读查询固定直接依赖的候选版本，产生包含目标地址、登录用户、端口及已核验主机密钥文件摘要的计划；用户核对软件源、目标和包清单后，才可显式批准系统安装。执行前重新检查系统、软件包版本和主机密钥文件摘要，变化则拒绝安装。

安装使用非交互 sudo 和系统 apt，固定直接包版本，关闭显式不安全仓库和未认证安装选项，保留旧配置文件；安装仍依赖系统软件源的实际信任配置和间接依赖解析，不提供完整锁文件及独立校验。工具不修改仓库配置、不执行未经校验的下载脚本、不启用驱动或服务。

计划、执行及连接结果都是目标系统提供的数据，不能证明主机安全。断线或超时可能发生在安装执行之后，结果标记为未知，不自动重试；失败时须检查远端 apt/dpkg 状态。安装需要明确授权，不因创建连接或检查环境自动触发。

## 验证与限制

离线测试、Ubuntu 系统支持、非交互 sudo、apt 配置、依赖下载、磁盘空间、异常恢复及升级回滚均待验证。用户需在维护窗口审查系统源与现有服务；未验收前不得接入服务端自动执行入口。配置桌面、驱动、SSH 隧道和跨电脑切换需要独立设计与实现。

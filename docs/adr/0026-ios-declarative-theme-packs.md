# ADR-0026：iPhone 声明式主题包与页面作用域

日期：2026-11-21。关联 PA-019、PA-020、PA-021。决策：按用户确认实施，当前进度见总计划。

主题包是本地 JSON 数据和内嵌受限 PNG/JPEG，不是可执行插件。通过现有模式令牌、受控布局及组件变体渲染；不反序列化 React 组件、脚本、任意样式或远程 URL。首版仅 iPhone，不增加原生依赖、服务器接口或数据库。

选择由一项全局绑定及按稳定页面类型保存的局部绑定构成。默认、全局、页面覆盖、局部及用户偏好依次合成。页面 Context 持有独立解析结果；不能通过全局当前路由变量提供颜色，避免导航中保留页面互相污染。局部渲染失败仅清理对应绑定。

主题文件置于应用 Documents 的专用目录，选择保存在版本化 SecureStore 记录；原模式记录仅作首次迁移及旧版回退。应用私有数据不上传服务器。系统授权界面、文件选择器及远程电脑内容不由包修改。协议、文件和图片上限及实际验证见专项评测和技术设计。

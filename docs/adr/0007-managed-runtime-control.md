# ADR-0007：受管任务的直通工具与控制轮询

状态：代码初版，尚未通过项目测试及真实服务器验收。日期：2026-11-04。关联 PA-004、PA-005、PA-006、PA-010、PA-014。

Pi 的部分工具在 runtime 内直接执行，不经过普通工具授权分发；自动模型审核也尚未计入 Task 预算。managed task 在暴露工具时采用受支持工具和授权条目的交集，暂不暴露 helper、`ask_user` 和接管等直通工具；managed 自动模型审核关闭，需要审批时沿用适用的人工审批策略。普通 Rakazo Run 不应用上述筛选。

managed runtime 期间增加 Task 控制状态轮询：启动前先查，之后约每两秒检查；暂停、取消、Run 不再匹配、截止或查询失败时触发 AbortSignal。native socket 收到该信号关闭连接，以便驱动尽力清理命令进程组。

排队取消在同一 Task 行锁事务内按 `managed_task` 和 `queued` 条件原子终止当前 Run，并清理可恢复状态；已被 Worker 领取的 Run 不转换为已静止。完成结果只在全 Task 历史无未结算 effect 且保存独立 completion evidence 后显示成功，历史不完整时保持不可确认。

此设计不保证进程静止、即时中断、外部副作用回滚，也不覆盖 runtime 启动前全部准备步骤。数据库读取到行为之间存在竞态；脱组进程及远端请求可能继续。停止确认保持失败关闭。只有通过真实 PostgreSQL、Linux 和模型/工具中断测试后才能评估验收。

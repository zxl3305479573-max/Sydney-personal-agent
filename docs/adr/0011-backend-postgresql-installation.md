# ADR-0011：后台 PostgreSQL 安装

日期：2026-11-04

状态：已实施，恢复与升级尚未演练。

## 背景与决定

后台机原有业务需要保留。项目自托管文档要求 PostgreSQL 16 或更高，系统默认软件源的 PostgreSQL 14 不满足要求。尝试拉取项目固定的 PostgreSQL 18 Docker 镜像时连接不稳定，因此安装原生 PostgreSQL 18，使用 PostgreSQL 官方签名的阿里云镜像软件源。安装过程同时升级系统已有的 `libpq5` 和 `libpq-dev`；现有服务启动状态已复查，未做其业务功能回归。

Sydney 使用独立数据库，迁移 owner 和非超级用户、不能绕过 RLS 的运行账号分离；数据库与 API 只监听本机。服务配置、密钥和数据路径见运维手册。当前服务账号同时用于既有隧道，不能将此视为两个应用之间的账号隔离。

## 后果

后续系统软件更新可能同时涉及 PostgreSQL 软件源及共享客户端库；升级前应检查既有业务依赖并安排备份和恢复验证。后台仅有约 1.7 GiB 内存，部署后的可用内存有限，尚未进行实际任务负载测试。账户、模型、端到端任务、重启和备份恢复不包含在本次验收内。

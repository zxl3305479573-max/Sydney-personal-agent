# ADR-NNNN：决策标题

- 状态：提议 / 已接受 / 已替代 / 已否决，保留一个实际状态
- 日期：YYYY-MM-DD
- 关联需求：PA-NNN
- 替代或被替代记录：无，或关联文档

## 背景

说明需要解决的实际问题、当前约束和决策时限。

## 候选方案

列出合理备选方案，比较实现成本、运行成本、隐私、可测试性和迁移成本。需要外部事实支持时记录核实日期与来源。

## 决策

说明选择的方案、适用范围和选择依据。提议状态写明待验证的假设。

## 影响与限制

说明收益、代价、配置变化、兼容性、数据迁移和已知限制。

## 验证与重新评估

说明验证方法、接受条件，以及哪些新情况会触发重新评估。

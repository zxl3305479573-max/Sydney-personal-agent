# ADR-0006：任务执行状态复用 Task 与 Run

日期：2026-11-03。状态：实施中。关联 PA-001、PA-003、PA-004、PA-005、PA-006、PA-010。

采用现有 PostgreSQL 和 Prisma，在 Task 增加可空的版本化执行状态、在 Run 增加可空的授权记录。旧任务保持原行为；新任务通过明确的服务入口创建，授权由经过认证的用户接口签发，不能从提示词或工具输出生成。

任务控制、当前 Run、完成证据和预算存入同一状态记录。事务以 Task 行锁串行化同一任务的变更，以版本检查拒绝过时的界面操作；不增加全局调度锁。执行工具时重新加载当前状态、授权和 Run 租约。现有审批继续独立生效。

迁移只增加列。部署时先停旧 Worker、应用迁移，再启用新 API/Worker，最后允许创建新任务；旧 Worker 不具备新门禁，不能在新任务创建后继续执行。仅 schema 向后兼容不等于安全策略向后兼容。

生产数据库、跨进程竞争和模型真实调用尚未验证。没有另建数据库、运行时、调度队列或模型厂商依赖。

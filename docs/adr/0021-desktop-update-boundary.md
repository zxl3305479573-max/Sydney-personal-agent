# ADR-0021：桌面更新源的信任边界

日期：2026-11-10。状态：实施中，安装包尚未验证。

## 背景

Sydney 的 Electron 打包配置仍指向上游 GitHub 更新源；符合条件的安装包默认会检查并下载可用更新。Windows 发布流程允许无签名产物，无签名包没有 Sydney 发布者绑定。已有配置不能证明更新来自 Sydney 控制的发布方。

## 决定

在 Sydney 独立更新源及发布者验证方案完成前，桌面客户端统一关闭自动和手动更新。现有更新状态接口继续返回不可用及提示，不改变服务器连接。此决定只作用于包含本次修改的新构建，不会远程改变已安装的旧版本。

当前保留上游打包与发布配置作为待处理事项，不将其视为 Sydney 的可信发布方案。重新启用前须确定用户控制的更新源、签名身份、安装身份迁移、发布流程和回滚，并在实际安装包中验证错误发布者、无签名、损坏及有效更新的行为。正式发布、密钥配置和更新服务另行实施。

## 后果与验证

关闭更新期间需要通过可信渠道手动获取新安装包。定向验证须确认后台和用户手动操作都不会加载更新器；真实网络、打包产物、签名与系统安装尚待验证。该决定不保证旧安装包已经关闭更新，也不宣称上游更新一定能被安装。

# ADR-0006：原生电脑动作前租约校验

状态：已实施初版，未完成类型检查、定向测试和真实服务器验收。日期：2026-11-04。关联 PA-004、PA-005、PA-006、PA-010、PA-012、PA-014。

原先 Executor 在创建 context 时写入固定八秒期限，长任务会过期，且该字段不能证明数据库租约仍有效。改为每次 native Provider 动作前，通过 Worker 的进程内回调读取匹配租户、Bot、Run、owner、fence、状态和有效期；存在共享电脑租约时再核对其电脑、Bot、Run、fence 和期限。驱动请求期限不得超过读到的最早到期时间及当前时间加八秒。managed 模型和工具门禁也检查 Run 租约期限。

该设计保留现有 Run 和电脑租约，不新增数据库或部署依赖。它并未消除数据库读取和驱动动作之间的竞态，短期凭据也不提供签名或防止同 UID 伪造；现有请求执行期间无法据此证明中断。需在授权 PostgreSQL/Linux 环境测试续期、丢失租约、并发、进程清理与权限，测试前不得视为生产保护。

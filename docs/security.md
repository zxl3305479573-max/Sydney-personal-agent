# 安全与隐私

状态：第一版实现约束。底座已有审批与租约；Sydney 的新增授权策略尚未接入实际执行，不能因此宣布安全验收完成。

## 1. 信任边界

用户通过可信交互入口提供任务和授权。模型响应、工具输出、网页、文件及检索内容都是待处理数据，不能自行扩大权限、修改策略、读取密钥或指示忽略用户要求。

工具调用必须经过确定性的参数和权限检查。提示词中的“请遵守权限”不能替代实际检查。

第一版只接入已明确登记的工具和 Provider。按 [ADR-0008](adr/0008-separate-control-and-desktop-hosts.md)，后台与云电脑分机，Agent 以桌面账号执行已授权操作，默认不获得任一服务器 root、sudo、后台密钥、数据库或服务管理权限；网络隔离和远端身份须实测。动态加载未知 Provider 或工具不属于第一版。

## 2. 授权策略

| 操作 | 默认处理 |
| --- | --- |
| 读取任务已授权范围内的普通文件 | 可直接执行，记录访问摘要 |
| 在已授权工作区创建或修改可恢复的文件 | 在任务明确授权范围内执行，记录变更 |
| 云电脑桌面、文件、终端和用户级应用 | 按用户预先授予的电脑和任务范围执行，不逐次确认点击和命令 |
| 系统级安装、root/sudo 与服务管理 | 首版默认禁止；后续必须独立审查授权和隔离方案，不能借桌面权限获取后台权限 |
| 读取工作区外的文件或新的账号资源 | 先取得覆盖该资源和用途的授权 |
| 发送消息、公开发布、购买、支付或删除不可恢复数据 | 必须有明确覆盖具体动作和范围的有效授权 |
| 读取控制服务密钥、宿主机凭据或云账号管理权限 | 不向客体和模型开放 |

有效授权可以在其范围内复用，不要求同一任务中的每次调用重复确认。任务中未授予的权限不得根据助手推测自动补齐。

授权至少限定任务、工具、动作、资源和有效期。外部收件人、公开目标、金额、文件范围等关键参数发生变化时，必须重新判断授权是否适用。

用户可以撤销授权。尚未开始的操作在执行前再次检查；已发出的外部请求可能无法撤回，应返回真实结果。

桌面权限不自动授权外部账户的发布、付款或其他动作。主机分离不能代替网络隔离及认证，也不能自动提供可信急停；云电脑 root 权限不属于默认授权。

P2 授权策略要求服务端提供可信的任务及 Run 绑定、精确工具/动作/资源条目、有效期和撤销状态；现有审批结论仍须允许。纯函数的允许结果只代表范围匹配，不签发授权、不证明调用者身份，也不完成持久化、资源规范化或租约校验。实际接入必须在执行前读取最新授权、核对 Run 的 fence 与接管状态；签发入口不能接受模型或网页提交的“可信来源”字段。

普通 GUI 点击无法可靠识别所有外部副作用，不能承诺“点击层检查能阻止一切越权”。需要通过专用账号、外部服务权限和控制侧网络策略共同限定影响范围。

## 3. 文件与网络边界

- 对文件路径做规范化并检查最终目标，拒绝目录穿越、前缀误匹配和越界的绝对路径。
- 上述工作区约束适用于普通文件工具；专属云电脑驱动按已授权客体范围访问，不能挂载控制服务器目录或宿主机管理套接字。
- 检查符号链接或 Windows 目录联接后的实际位置，防止绕过工作区限制。
- 临时文件、输出目录和写入后的目标同样受资源范围约束。
- 网络工具限定必要的目标和协议；限制响应大小、重定向、超时和访问频率。
- 如实现网页抓取，阻止未授权的回环、内网和实例元数据访问，重定向后的地址重新校验。
- 云电脑可访问已配置的本机桌面和驱动端口；它到控制面、其他内网资源和云实例元数据的访问另行隔离，不因可上网而自动放通。
- Provider 管理凭据仅保存在控制侧，桌面连接使用短期凭据；支持撤销，界面不暴露长期供应商密钥。
- 对大量内容使用摘要或截断，避免无限扩大上下文和存储占用。

## 4. 密钥与模型调用

- 密钥只通过选定的安全配置方式加载，不写入源码、示例、普通日志或模型上下文。
- 任务使用的文件内容只在完成任务必需且授权允许的范围内发送给模型。
- 接入远程模型时说明供应商、发送内容类型和配置入口，不将“本地保存”描述成“数据不出本机”。
- 模型端的数据保留和训练政策以所选服务的实际政策为准，选型时核实并记录。
- 故障信息和调试输出也必须脱敏，不回显完整请求头和访问令牌。

## 5. 个人数据生命周期

- 将会话记录、执行记录和长期记忆分开保存，说明各自用途和存储路径。
- 长期记忆以用户明确保存为准，不在后台推断并保存敏感画像。
- 记忆修改、删除同步作用于相关检索索引或缓存，后续查询不能继续返回旧值。
- 删除界面明确实际范围：当前记忆、历史会话、任务记录和备份分别处理。
- 备份与原始数据具有同等敏感性，不把备份加入仓库。
- M0 明确保留期限和备份策略；第一版交付前提供数据清理和恢复说明。
- 不承诺文件删除等同于介质级安全擦除；如有更高需求，单独设计。

## 6. 失败、重试与审计

- 只读操作可按有限次数重试，仍受超时和任务预算约束。
- 有副作用操作重试前检查幂等能力和已执行记录。
- 超时或进程中断导致结果未知时，先通过状态查询或用户核对确认结果，不盲目重放。
- 保存工具名、任务与步骤编号、授权引用、时间、结果摘要和错误类别。
- 审计不默认保存完整文件内容、密钥和模型内部推理。
- 截图可能包含账号和个人信息，不默认长期保存；手动输入密码时暂停截图发送和录制，但不承诺客体管理员无法读取客体内凭据。
- 从一个 Provider 切换到另一个时核验新目标和授权；旧电脑的释放、账单与数据保留单独处理。
- 向用户说明已完成的动作、未完成的部分和是否存在结果未知的操作。

## 7. 第一版安全验收

| 场景 | 预期 |
| --- | --- |
| 外部文档要求助手上传密钥 | 不授予权限、不上传，原任务仍按有效授权处理 |
| 文件路径通过 `..` 或目录联接越界 | 调用被拒绝，目标未读取或修改 |
| 授权文件 A 后请求修改文件 B | 不复用 A 的授权 |
| 用户拒绝或撤销授权 | 相应未开始的操作不执行，并保存原因 |
| 有副作用请求超时后重启 | 标记结果未知，不自动重复发送 |
| 删除某条长期记忆 | 后续记忆检索无法返回该条内容 |
| 查看普通日志 | 不出现密钥或未经必要处理的敏感原文 |
| 人工接管同一桌面 | Agent 的输入通道被阻断，不能与人工同时点击 |
| 原生云电脑人工接管 | 独立 `controlLeaseId` 和递增 `controlFence` 校验，撤销后旧租约及旧输入票据被拒绝；VNC 保持只读 |
| 客体内驱动被停止或修改 | 控制侧仍可撤销连接；受管 Provider 可在独立控制面停止实例 |
| 替换 Provider 后重放旧输入 | 旧会话代次的请求被拒绝，不落到新电脑上 |

上述要求需通过实现和验收建立证据，不能仅凭文档宣称满足。

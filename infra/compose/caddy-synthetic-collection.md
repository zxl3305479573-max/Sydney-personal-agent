# I1 Caddy 合成采集候选

**状态：CLI 硬阻断。** 参数校验后直接以非零退出，不创建夹具、密钥或子进程；
独立审查前不得在服务器执行。内部组件仅供代码审查和隔离测试。

候选范围：自建两个普通目录模拟卷，使用临时密钥和现有非 root 合成采集器进行加密，
再在内存中解密并核对固定内容、归档成员、目录及文件的数字 UID/GID、模式及清单。
不接受输入路径、卷名、Docker 地址、收件人或输出路径；不连接 Docker daemon，
不读取真实卷，不保留密文和临时私钥。这是目录夹具，不是 Docker named volume
或生产完整卷采集验收。

依赖 Linux x86_64/aarch64、非 root 且真实/有效/保存 UID 一致、可信 Python、
`/usr/bin/age`、`/usr/bin/age-keygen`、同目录的
`backup-caddy-volumes-encrypted.py`、支持 openat2 和 seccomp 的内核。启动环境、
系统程序、脚本及 `/tmp` 的宿主机须可信；独立审查前不在服务器执行。
现有 CLI 不提供解除阻断的参数或环境变量。

CLI 可设置 `--max-output-bytes`（16 KiB–16 MiB，默认 1 MiB）、
`--reserve-bytes`（1 字节–1 GiB，默认 1 MiB）、`--timeout`（1–120 秒，
默认 30 秒）。目前这些参数仅做校验，不触发采集。候选内部大小由既有采集器限制，空闲空间检查不是独立配额；
超时是各子进程分别的上限，不是整个 CLI 的总时限。
采集器及其 age 子进程的候选进程组由外层清理：受信启动器覆盖 age 新建会话，
遇到可处理的中断或超时后杀整个组并等待采集器。该方案尚未在 Linux 实测；
内部 `run_capture` 已增加 SIGINT、SIGTERM 和 SIGHUP 处理，测试控制器不再
自行安装 SIGTERM 处理器；此修改尚未独立审核或在 Linux 验证。
只依靠进程组不能保证 wrapper 收到 SIGKILL、系统崩溃、进程逃逸或不可中断睡眠时
清理，孤儿及私有临时目录可能残留。因此入口继续硬阻断，直到外部生命周期监督、
终止及失败报告方案经独立审查和隔离实测。中断测试不能证明这些极端情况已解决。
不保证网络隔离，可信程序和宿主机仍可访问网络；临时密钥仅供合成实验。

未覆盖 Docker daemon 身份、真实 named volume、卷挂载竞争、ACL/xattr、硬链接、
真实生产一致性、实际恢复目录及 Caddy 启动。现有采集器拒绝 ACL/xattr；
不得将此 CLI 接入生产或视为原有硬阻断的替代。建议独立审查重点检查启动与
程序可信性、继承 FD、终止及残留、资源限制、假加密和归档验证；随后在维护机
以真实 age 和受控隔离环境复验。生产回滚已有用户授权，但仍需按既定技术门禁执行。

写集限定阻止同步修改 `docx/PLAN.md`、开发记录、验证记录和运维手册；本次状态
保持 I1 进行中，待允许更新这些文件时同步本候选与真实验证结果。
